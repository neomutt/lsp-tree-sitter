# Install

Example language servers are similar.

## [AUR](https://aur.archlinux.org/packages/lsp-tree-sitter)

```bash
paru -S python-lsp-tree-sitter
```

## [NUR](https://nur.nix-community.org/repos/Freed-Wu)

```bash
nix-env -iA nixos.nur.repos.Freed-Wu.lsp-tree-sitter
```

## [PYPI](https://pypi.org/project/lsp-tree-sitter)

```bash
pip install lsp-tree-sitter
```
